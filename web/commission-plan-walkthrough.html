ของเดิม กับ แผน

ยังไม่ตั้ง (ระบบเดิม) — ร้านมี "% ร้าน" ที่พิมพ์เอง (เช่น 17%) กองทุนจ่ายทั้งก้อนวันเปิดสัญญา ถ้าลูกค้าหยุดจ่ายเร็ว ร้านถูกเรียกคืนตามกติกาคืนค่าคอม

แผน — ชุดสำเร็จรูปที่กองทุนกำหนดไว้ (เลือกได้ แก้ไม่ได้) บอกว่าจ่ายกี่ก้อน ก้อนละกี่ % ปลดเมื่อไร เช่น 7% + 5% + 5% (งวด 1, 2) = วันเปิด 7% · ลูกค้าจ่ายงวด 1 ครบ อีก 5% · งวด 2 ครบ อีก 5%

ร้านที่อยู่บนแผน ไม่ใช้ "% ร้าน" อีก — ส่วนของร้านมาจากแผนทั้งหมด ส่วน "% บริษัท" ยังใช้เหมือนเดิม สัญญาที่เปิดไปแล้วล็อกตัวเลข ณ วันเปิด เปลี่ยนแผนทีหลังไม่กระทบ

ก้อนค่าคอม 1 ก้อน ไล่สถานะอย่างไร ระบบ
  • ก้อนวันเปิด · รอใบขอรับเงิน — ก้อนแรก (pay_no 0) ไม่ได้มาทางนี้ มันอยู่บนใบขอรับเงินของร้านใบเดิม (ค่าเครื่อง + ค่าคอมวันเปิด)
  • ค่าคอมที่รอการจัดเก็บค่างวด — ก้อนที่ผูกกับงวดที่ลูกค้ายังไม่จ่าย
  • ปลดแล้ว · รอพ้นวันของบิล — ลูกค้าจ่ายงวดนั้นแล้ววันนี้ รอให้วันของบิลผ่านไปก่อน (กันบิลถูกยกเลิกในวัน)
  • ปลดแล้ว · รอครบกำหนด — ช่วงถือตามนโยบาย holding (DEV: 7 วัน) กันลูกค้าขอคืนเงิน
  • พร้อมรวบ — การเงินกดรวบได้
  • อยู่ในใบ → จ่ายแล้ว — อยู่บนใบค่าคอมส่วนเพิ่ม แล้วถูกจ่าย
  • ไม่เกิด (สัญญาสิ้นสุด) — สัญญาจบก่อนลูกค้าจ่ายถึงงวดนั้น ก้อนนี้ไม่มีวันเกิด
ตัวเลขทุกตัวบนจอมาจากฝั่งหลังบ้านตรง ๆ หน้าจอไม่คำนวณเอง — ร้านกับการเงินจึงเห็นเลขเดียวกันเสมอ

1 ผู้ดูแลตั้งแผนให้ร้าน ADMIN

หน้า "เงื่อนไข Deal Partner" ใต้เมนูราคา · ตารางร้านท้ายหน้า · /admin/pricing/deal-partner-rates

สิ่งที่เห็น

ตารางร้านบอกทันทีว่าร้านไหนอยู่บนแผน ร้านไหนยังระบบเดิม ปุ่ม เปลี่ยน ในคอลัมน์ค่าคอมเปิดหน้าต่างเลือกแผนอย่างเดียว ส่วนดินสอขวาสุดเปิดหน้าต่าง แก้ไขเงื่อนไขร้าน ที่มีทุกเงื่อนไข (แผนเป็นบรรทัดแรกในนั้น)

ตารางร้าน deal partner /admin/pricing/deal-partner-rates ADMIN
  • ร้านบนแผน: ชื่อแผนนำ แล้วตามด้วย บริษัท 0% — ไม่มี "% ร้าน" เพราะไม่ได้ใช้
  • ร้านระบบเดิม: 17% · ร้าน 17% · บริษัท 0% แล้วบรรทัด ยังไม่ตั้ง (ระบบเดิม)
  • เปลี่ยน ข้างแผน = เปิดหน้าต่างเลือกแผน · ดินสอ = หน้าต่างเงื่อนไขทั้งหมด
หน้าต่าง แก้ไขเงื่อนไขร้าน — ร้านที่อยู่บนแผน ADMIN
  • บรรทัดแรก แผนค่าคอม กับปุ่ม เปลี่ยน และคำเตือน "แผนมีผลกับสัญญาที่เปิดหลังจากตั้ง · สัญญาที่เปิดไปแล้วใช้แผนเดิมจนจบ" (ถ้อยคำที่ owner เคาะ)
  • มีแค่ % บริษัท — ช่อง % ร้าน และกล่อง % รวม ไม่แสดง เพราะบนแผนไม่ได้ใช้
  • ที่เหลือเหมือนเดิม: ค่าทำสัญญา, ค่าคืนเครื่องในระยะประกัน, สาขารับเครื่องคืน, กติกาคืนค่าคอม, บัญชีรับเงินของร้าน, หมายเหตุ
  • บันทึกแล้วขึ้นหน้าสรุป (ไม่ปิดเอง) · ปิดทั้งที่ยังไม่บันทึกจะถูกถามก่อน
หน้าต่างเดียวกัน — ร้านที่ยังระบบเดิม ADMIN
  • แผน = ยังไม่ตั้ง (ระบบเดิม)
  • มีครบ % ร้าน % บริษัท และกล่อง % รวม ที่ต้องอยู่ในช่วงที่ holding กำหนด (DEV: 10–20%)
  • พิมพ์ให้รวมเกินช่วง → กล่องรวมเป็นแดง ปุ่มบันทึกกดไม่ได้
หน้าต่าง แผนค่าคอม (เลือกแผน) ADMIN
  • เปิดจากปุ่ม เปลี่ยน ทั้งในตารางและในหน้าต่างเงื่อนไขร้าน — หน้าต่างเดียวกัน
  • การ์ดละแผน: ชื่อ · ยอดรวม · ก้อนละกี่ % ปลดตอนไหน · คำอธิบายจากกองทุน · ป้าย ใช้อยู่ บนแผนปัจจุบัน
  • การ์ดสุดท้าย ยังไม่ตั้ง (ระบบเดิม) = ถอดแผน กลับไปใช้ % ร้าน
  • แผนที่กองทุนปิดไปแล้วแต่ร้านยังใช้อยู่ ยังแสดงพร้อมป้าย "ปิดใช้แล้ว" (ยังมีผล) — DEV ยังไม่มีกรณีนี้
  • บันทึกส่งเฉพาะแผน เงื่อนไขอื่นไม่ถูกแตะ · ขึ้นหน้าสรุป "บันทึกแผนค่าคอมแล้ว" เดิม → ใหม่

เกิดอะไรตอนสัญญาใช้งาน

วันที่สัญญาร้านเป็น "ใช้งาน" ระบบประทับแผนและตัวเลขลงสัญญา แล้วสร้างก้อนตามแผน ก้อนวันเปิดไปอยู่บนใบขอรับเงินใบเดิมของร้าน ก้อนที่เหลือรอลูกค้าจ่ายงวด สัญญาเก่าที่เปิดก่อนมีแผนถูกแปะว่า แบบเดิม: จ่ายครั้งเดียววันเปิด + เรียกคืน และมีก้อนเดียว

ค่าคอมร้าน — แท็บ สัญญา /admin/shop-commission/97930 FINANCE
  • รางซ้าย: สัญญาละแถว — เลขสัญญา, ป้ายสถานะค่าคอม (มีก้อนรอจ่าย / จ่ายครบแล้ว / สัญญาสิ้นสุด / รอการจัดเก็บค่างวด), ยอดค่าคอมตามแผน, ลูกค้า · ร้าน, ชื่อแผน, วันเปิด
  • ค้นหาด้วยเลขสัญญาหรือชื่อลูกค้า · กรองวันเปิด · กรองสถานะ · ลูกศรขึ้นลงเดินแถวได้
  • ขวา: หัวสัญญา (ลิงก์ไปหน้าสัญญา) · การ์ดสรุป · รายการ ก้อนค่าคอม (3) ก้อนละบรรทัด พร้อมสถานะและวันที่ปลด
  • แท็บและสัญญาที่เลือกอยู่ในที่อยู่หน้า — กดย้อนกลับได้ ก๊อปลิงก์ให้คนอื่นเปิดเจอจอเดียวกัน
ค่าคอมร้าน — แท็บ รายเดือน /admin/shop-commission?tab=monthly FINANCE
  • เดือนละแถวต่อร้าน (เดือนตามวันเปิดสัญญา): ยอดค่าคอมตามแผนรวม · จำนวนสัญญา · ยอดจัดรวม · แยกตามสถานะก้อน
  • ตัวเลขแยกสถานะ เช่น รอใบขอรับเงิน 3,546 รอการจัดเก็บค่างวด 480 จ่ายแล้ว 10,988 ไม่เกิด 1,632
  • กดเดือนไม่เปลี่ยนด้านขวา — ด้านขวายังแสดงสัญญาที่เลือกไว้จากแท็บสัญญา

3 การเงินรวบก้อนเป็นใบจ่าย FINANCE

หน้า "เอกสารเงินของกองทุน" แท็บใหม่ ค่าคอมส่วนเพิ่ม · /admin/fund-bills

เมื่อก้อน "พร้อมรวบ"

การเงินกด รวบ ที่ร้านนั้น → ก้อนที่พร้อมทั้งหมดของร้านรวมเป็นใบร่าง 1 ใบ ชนิดใหม่ "ใบค่าคอมส่วนเพิ่ม" จากนั้นเดินเหมือนใบจ่ายร้านใบอื่น: ออกใบ → จ่าย (แนบสลิปได้) → ก้อนกลายเป็น จ่ายแล้ว พร้อมเลขใบและวันที่ ทั้งหน้าการเงินและหน้าร้าน ถ้าจ่ายผิด ใช้ใบลดหนี้เหมือนเดิม

เอกสารเงินของกองทุน — แท็บ ค่าคอมส่วนเพิ่ม /admin/fund-bills?shop=7 FINANCE
  • ร้านละแถว: พร้อมรวบ N ก้อน และก้อนที่ยังรออยู่แยกเหตุผล (รอปิดวัน / รอพ้นวัน / รอครบกำหนด) · ปุ่ม รวบ บนแถวโผล่เฉพาะร้านที่มีก้อนพร้อม
  • กดแถว → ด้านขวาแสดงก้อนของร้านนั้นเป็น 2 กลุ่ม: พร้อมรวบ และ รออยู่ ก้อนละบรรทัด บอกสัญญา ก้อนไหน สถานะ วันที่ และยอด
  • รวบ มุมขวาบนของแผงกดได้เมื่อมีก้อนพร้อมอย่างน้อย 1 ก้อน · เปิดหน้าต่างยืนยัน → ใบร่าง 1 ใบ
  • ใบที่รวบแล้วไปโผล่ในแท็บ ร่าง → ออกใบแล้ว → ชำระครบ เหมือนใบจ่ายร้านเดิม
หน้าต่าง รวบใบค่าคอมส่วนเพิ่ม — ยังไม่มีก้อนพร้อม FINANCE
  • บรรทัดใต้ชื่อร้านบอกเหตุผล: ยังไม่มีก้อนพร้อมรวบ · รอพ้นวัน 1 · ปุ่ม รวบ กดไม่ได้
  • เมื่อมีก้อนพร้อม บรรทัดนี้จะเป็น "พร้อมรวบ N ก้อน · ยอด" และปุ่มกดได้ → ใบร่าง 1 ใบ → หน้าสรุปพร้อมปุ่มเปิดใบ
หลังเที่ยงคืน — ก้อนพร้อมรวบจริง /admin/fund-bills?shop=7 FINANCE
  • วันที่ 12 ต.ค. 00:19 (ช่วงถือตั้งเป็น 0 บน DEV): แถวร้านขึ้น พร้อมรวบ 8 ก้อน · 6,768 และปุ่ม รวบ บนแถวโผล่
  • แผงขวา "พร้อมรวบ (8)" จัดกลุ่มตามสัญญา 5 สัญญา บอกจำนวนก้อนและยอดต่อสัญญา กดลูกศรเพื่อกางดูทีละก้อน · "รออยู่ (0)" ว่าง
รวบ → ใบร่าง → ออกใบ → จ่าย FINANCE
  • หน้าต่างรวบ บอก "พร้อมรวบ 8 ก้อน · 6,768" และปุ่ม รวบ กดได้ · กดแล้วได้ใบร่าง FB-2610-000007-9 หน้าสรุปบอกว่าใบไปอยู่แท็บ ร่าง และร้านหายจากคิว · ปุ่มหลัก ไปที่ใบร่าง
  • ใบร่าง บรรทัดละก้อน บอกสัญญา ก้อนไหน % ยอด · แก้บรรทัดไม่ได้ (ยกเลิกใบได้ ก้อนกลับเข้าคิว)
  • ออกใบ หน้าต่างยืนยันเตือนว่าบรรทัดจะถูกล็อก · หน้าสรุป ร่าง → ออกใบแล้ว · ปุ่มหลัก บันทึกจ่ายเงิน เปิดหน้าต่างจ่ายใบเดียวกันต่อทันที
  • บันทึกจ่ายเงิน เลือกบัญชีที่จ่าย วันที่ เลขอ้างอิง แนบสลิปได้ · ใบค่าคอมไม่มีกล่อง "สองฝั่ง" เพราะไม่มีส่วนของบริษัท · หน้าสรุปบอกว่าก้อนเป็น "จ่ายแล้ว" และร้านเห็นในหน้าค่าคอมของฉัน
